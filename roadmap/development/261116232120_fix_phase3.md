# Phase 3 の軽微な修正（fix）

## 261116232120 ウィンドウの取り込み：画面が変わらないと、プレビューが出ず、黒い画面の判定も進まない

- **内容**：Windows.Graphics.Capture は、ウィンドウの中身が変わったときにしかフレームを送らない。そのため、(1) 変化のないウィンドウでは、最初の1枚のプレビューを受け取れなかった画面（あとから開いた映像のページなど）に「映像がありません」と出続け、(2) 黒い画面のまま止まると、`frame_processor` の「1.5秒続いたら画面が消えた」の判定が進まず、パネルを隠さなかった。また、変化のないウィンドウで手動の切り抜きを動かしても、オーバーレイの範囲が変わらなかった
- **直したこと**：`FrameProcessor` に `tick`（フレームが来ない間、最後の判定のまま時間だけを進める）を足し、`BlackBarProcessor` で実装した（単体テスト1件）。映像のスレッドは、フレームを待ってタイムアウトしたときに `tick` を呼び、切り抜きが変われば表示へ渡し（`OpenVrOverlayPresenter::set_crop`）、最後のプレビューを1秒ごとに送り直す
- **見つけた経緯**：T3-9の後、`tauri dev` の画面をWebView2のCDPで操作して確かめたとき、取り込み中と同じウィンドウを映像のページで選び直すと、プレビューが出なかった
- **軽微とした根拠**：要件・設計・タスク構成・確定事項を変えない。`FrameProcessor` のメソッドの追加は、imple 2章の「細部は実装で確かめて決める」の範囲で、UIとの境界（Tauriのコマンドとイベント）は変えていない
- **確かめたこと**：checkコマンドが通る。手元のアプリで、同じウィンドウのまま映像のページを開き直してもプレビューが出る
